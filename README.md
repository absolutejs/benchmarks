# absolutejs benchmarks

Performance & accuracy benchmarks for the AbsoluteJS suite. Each subdirectory is
a standalone project that consumes the published packages.

- [`voice/`](./voice) — `@absolutejs/voice` STT/TTS/duplex/telephony/session benchmarks vs. Vapi.
- [`sync/`](./sync) — `@absolutejs/sync` shared-counter latency/throughput vs. Zero and Convex.
